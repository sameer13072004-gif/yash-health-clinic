## 🎨 Three-Tier CSS Design Token System

The entire UI is built with zero hardcoded hex values in component selectors, enforcing a strict 60-30-10 surface allocation:

```
├── Tier 1: Primitive Tokens
│   ├── Spacing Scale: 4px / 8px rhythm (--space-1 to --space-24)
│   └── Radius Scale: --radius-sm (6px), --radius-lg (12px), --radius-pill (9999px)
│
├── Tier 2: Semantic Tokens (60-30-10 Allocation)
│   ├── 60% Dominant Canvas: #FFFFFF (Sterile Clinical White)
│   ├── 30% Structural Band: #F6F9FC (Soft Off-White), #F5F7F6 (Warm), #273951 (Deep Slate)
│   ├── 10% Action Accent: #24B47E (Vitality Emerald Green for CTAs & WhatsApp)
│   ├── Brand Authority: #2779A7 (Clinical Petrol Blue)
│   └── Ink: #273951 (Primary Deep Ink — eliminating pure #000000 glare)
│
└── Tier 3: Component Tokens
    └── --container-max-w (1200px), --nav-height (64px), --shadow-floating
```

4. **6-Wing Clinical Departments Bento Grid:** Asymmetric 3-column Bento grid with Wing 01 spanning 2 columns, featuring 1-click smooth-scroll and combobox auto-selection.
5. **Chief Medical Officer Portfolio Spotlight:** Executive editorial dossier covering qualifications, clinical philosophy, verbatim review quote, and 3 verifiable commitments.
6. **How Your Visit Works (4-Step Timeline):** Numbered steps (01 to 04) connected by a 1px hairline rail.
7. **Inside Our Clinic & Facilities:** 4-card 4:3 facility showcase (Consultation Chamber, In-House Dispensary, Maternal & Child Nursing Room, Clinic Entrance).
8. **Verified Google Reviews Wall:** 100% real verbatim Google patient reviews with 1:1 circular avatars and Google verification badges.
9. **Transparent OPD Fee Structure:** Transparent rate card (₹200 Standard OPD, ₹350+ Medicine Kit, Custom Family Chronic Plan) with tabular numerals (`tnum`).

12. **Mobile Sticky Thumb-Zone Bar (<768px):** Fixed bottom conversion bar featuring Click-to-Call + WhatsApp Doctor.

## 🚀 Local Development

To run the site locally:

```bash
# Clone the repository
git clone https://github.com/sameer13072004-gif/yash-health-clinic.git
cd yash-health-clinic

# Start the local server
node serve.js
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
